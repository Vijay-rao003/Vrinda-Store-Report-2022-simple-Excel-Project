# Vrinda-Store-Report-2022-simple-Excel-Project
Excel Dashboard 
project presents an interactive Annual Sales Dashboard for Vrinda Store (2022) built using Microsoft Excel / Power BI.
The dashboard analyzes sales performance, customer demographics, order status, product categories, sales channels, and regional performance to support business decision-making.
Project Objectives:
Track monthly sales and order trends
Analyze men vs women purchasing behavior
Monitor order fulfillment status
Identify top-performing states
Understand sales distribution across channels
Enable interactive filtering for deeper insights
